## 📸 Application Preview

The following screenshots demonstrate the interactive user interface and the output produced at each stage of the Natural Language Processing pipeline. Each module can be executed individually or together using the **Run All Steps** option.

### 🏠 Home Page

Displays the main dashboard where users can enter text, select an NLP operation from the sidebar, and execute the analysis.

![Home](images/home.png)

---

### ✂️ Sentence Segmentation

Splits the input paragraph into meaningful individual sentences.

![Sentence Segmentation](images/sentence_segmentation.png)

---

### 🔤 Word Tokenization

Breaks the text into individual words and punctuation tokens.

![Word Tokenization](images/word_tokenization.png)

---

### 🚫 Stop Word Removal

Removes commonly occurring words that contribute little semantic meaning.

![Stop Word Removal](images/stopward_removal.png)

---

### 🌱 Stemming

Reduces words to their root form using the Porter Stemming algorithm.

![Stemming](images/stemming.png)

---

### 📖 Lemmatization

Converts words into their dictionary base form using the WordNet Lemmatizer.

![Lemmatization](images/lemmatization.png)

---

### 🏷️ Part-of-Speech (POS) Tagging

Assigns grammatical categories such as nouns, verbs, adjectives, and adverbs to each token.

![POS Tagging](images/pos_tagging.png)

---

### 🧩 Named Entity Recognition (NER)

Detects and classifies named entities such as people, organizations, locations, and dates.

![Named Entity Recognition](images/NER.png)

---

### 🔗 Dependency Parsing

Visualizes the grammatical relationships between words to illustrate sentence structure.

![Dependency Parsing](images/dependency_parsing.png)

---

### 📄 Noun Phrase Chunking

Extracts meaningful noun phrases from the text for further linguistic analysis.

![Noun Phrase Chunking](images/noun_phrase_chunking.png)
