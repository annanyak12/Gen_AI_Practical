# Word Embeddings using Word2Vec (CBOW and Skip-gram)

## 📌 Overview

This project implements **Word Embeddings using Word2Vec** with two approaches:

- **CBOW (Continuous Bag of Words)**
- **Skip-gram**

The project focuses on generating word embeddings and comparing the **semantic similarity between words** using their learned vector representations.

## 🎯 Objectives

- Implement Word2Vec using CBOW.
- Implement Word2Vec using Skip-gram.
- Generate vector representations of words.
- Calculate semantic similarity between words.
- Compare CBOW and Skip-gram similarity results.
- Visualize word relationships using a similarity matrix.

## 🛠️ Technologies Used

- Python
- Gensim
- NumPy
- Pandas
- Plotly
- Scikit-learn
