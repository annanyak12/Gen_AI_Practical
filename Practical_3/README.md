# Implementation of Neural Language Models (RNN, LSTM and GRU) for sequence modeling and next-token prediction.

## 📌 Project Overview

This project implements a **Next Word Prediction system** using three different Recurrent Neural Network architectures:

- **Simple RNN**
- **LSTM (Long Short-Term Memory)**
- **GRU (Gated Recurrent Unit)**

The model is trained on text data provided in `input.txt`. The text is tokenized and converted into **N-gram sequences**, which are then used to train the neural network models. Given a sentence, the trained model predicts the most likely next word.

The implementation was developed and executed using **Google Colab**.

---

## 🎯 Objectives

- Understand the working of sequence-based neural networks.
- Implement text tokenization and N-gram generation.
- Build a next-word prediction model.
- Implement and compare:
  - Simple RNN
  - LSTM
  - GRU
- Understand how different recurrent architectures handle sequential text data.
